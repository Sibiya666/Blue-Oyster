# Бармен: все каналы своего сервера и поиск владельца

**Goal:** отвечать по прежним правилам обращения во всех каналах своего сервера; только настоящий Discord ID владельца получает возможность поиска. Сначала тестовый стенд.

**Architecture:** плагин Hermes проверяет сервер на входе. Отдельный, не сохраняющий общую историю запрос владельца к OpenRouter получает только серверный инструмент web_search (Exa, один поиск, три результата). Остальные пользователи идут обычным путём Hermes без инструментов. Приложение не загружает URL, не выполняет код и не передаёт модели секреты. Текст страниц недоверенный; это ограничение промпта, а отсутствие инструментов и секретов обеспечивается кодом.

Альтернативы: глобально включить инструменты Hermes — нарушает изоляцию; отдельная slash-команда — требует менять способ обращения. Выбран существующий входной хук без изменения Hermes. Для владельца запрос изолирован от истории канала; продолжение нужно формулировать самодостаточно.
